What changed from 114M

16 layers, each with one shared expert and 64 small routed experts, of which every token uses 4. Routing is balanced without an auxiliary loss (Quantile Balancing). A new 49,152-token tokenizer, trained for this model, keeps code indentation intact and covers ten languages.

Every design switch was A/B tested at 200M tokens before the full run, and the losers are published too. Muon beat AdamW clearly: 3.32 vs 4.06 loss, against seed noise of 0.03.

Data: 60% permissively licensed code, 28% English, 12% Indonesian, Malay, Chinese, Japanese, Korean, Tamil, Hindi and Urdu, each document checked with my own language-ID model. HumanEval and MBPP were filtered out of the training data.

Distillation

Keep only the answers that pass their tests.

The chat model could barely write code: greedy decoding solved 5 of MBPP's 257 problems. So an open-weight teacher, Qwen2.5-Coder-1.5B-Instruct (Apache-2.0), answered 5,000 coding problems, and every answer was run against the problem's unit tests in a sandbox. Only the 3,277 that passed were kept. The chat fine-tune was then repeated with those added.

1.9% → 7.4%MBPP pass@1, greedy (5 → 19 of 257)
0% → 0.6%HumanEval pass@1, greedy (0 → 1 of 164)
honest scale

About 4x better, and still low.

SantaCoder (1.1B) reports around 35% on MBPP and Qwen2.5-Coder-1.5B about 69%, with different settings. Quipu uses 149M parameters per token and saw 4.26B tokens. It is not competing with them yet.

Architecture

Decoder-only transformer in the modern style: RMSNorm, rotary position embeddings, SwiGLU feed-forward, and grouped-query attention with 12 query heads sharing 4 key/value heads. Input and output embeddings are tied, and the context is 1,024 tokens.

Short context by design. Long-range recall is meant to come from memory rather than a longer attention window.

Data

Three billion tokens: mostly text, one-fifth code.

80% FineWeb-Edu, 20% code from github-code-clean. Only permissive licences are kept: MIT, Apache-2.0, BSD, ISC, CC0 and Unlicense. Minified files, vendored directories and files over 16k tokens are filtered out. That filter alone removed as many tokens as the entire code budget.

Engineering

The failures that don't announce themselves.

Most of the work in a long unattended run is catching things that fail silently. Each of these was found in review, before the run.

01 · speed

Attention was quietly using a slow kernel.

Fixing the fallback took the projected run for the original budget from ~65 hours to ~39.

02 · I/O

About 1 in 130 file renames fails transiently.

That is enough to kill a 50-hour run over a log write. Every atomic write now retries.

03 · resume

A resume could restart from zero, silently.

After days of training, with no error. It now refuses unless nothing could have been saved.

04 · numerics

One bad batch could have deleted every clean checkpoint.

Non-finite steps are now skipped, and three in a row stop the run before retention prunes the good ones.

verdict

Fluent, on topic, and often wrong.

The final model says the printing press was invented "in 1848 by the French printer Pierre-Louis Leclerc". That is the honest result for a 114M base model: it has learned the form of knowledge without reliable facts, and it still repeats itself under greedy decoding.

caveat · code

The code loss of 0.97 flatters it.

GPT-2's tokenizer splits indentation into single spaces: 36.5% of the code validation tokens are pure whitespace, against 2.0% for text. They are easy to predict, and greedy code output collapses into runs of spaces. That measurement is why the next model gets a code-aware tokenizer.

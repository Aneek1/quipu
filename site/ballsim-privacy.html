ballsim privacy policy

Effective 27 October 2026. ballsim is a video renderer that runs on its owner's own computer and makes the videos for the GG Replay YouTube channel. This page explains what it does with data from a YouTube account it is signed in to. It has one user: the channel's owner.

What it accesses

With the account holder's permission, given on Google's sign-in screen, ballsim uses these Google APIs:

  • YouTube Analytics API (read-only): the channel's own report numbers, such as views, watch time, retention, traffic sources and viewer countries.
  • YouTube Data API, read-only: the channel's public details and its list of videos.
  • YouTube Data API, upload: uploading a video, with its title, description, tags and thumbnail, only when the owner runs the upload command for that video.

ballsim does not read comments, messages, playlists, subscriber identities or anything else from the account, and it never changes or deletes existing videos.

How it uses and stores it

  • The numbers are shown in the owner's terminal and stored in a database file on the owner's computer, to compare how different videos performed.
  • The sign-in token is stored in a file on the owner's computer. It is never sent anywhere except to Google, to make the API requests above.
  • There is no ballsim server. No data from Google is sent to the developer, to any third party, or to any advertising, analytics or AI service, and none of it is sold.

ballsim's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be removed at any time on the Google Account permissions page. The stored token and numbers are deleted by deleting the files on the owner's computer.

YouTube and Google

ballsim uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy.

This website

quipulm.dev counts page views with Cloudflare Web Analytics, which sets no cookies. The site has no sign-in and does not collect YouTube data.

Contact

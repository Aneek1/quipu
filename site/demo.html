01 Demo

A real session with the chat demo.

Recorded on 16 October 2026 from the live demo, not edited, at about real speed. The model is quipu-moe-1B-A149M-chat-distill running on a small CPU machine. Two turns: one it mostly gets right, one it gets wrong.

turn 1 · palindrome

The function works. Its test comments don't.

It lowercases, drops punctuation and compares the string with its reverse, which is correct. The comments next to the test calls are wrong: "This is a test" is not a palindrome, and "a" is.

turn 2 · follow-up

It loses track of the conversation.

Asked to change the function and add a docstring, it writes an unrelated function. Almost all of its chat fine-tune was one-question conversations, so follow-ups are weak. Multi-turn training data, where every step is checked by tests, is being built to fix this.

# Distillation v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a resumable pipeline that turns up to 1M OpenCodeInstruct problems into execution-verified, explain-first teacher answers (Qwen2.5-Coder-7B-Instruct), generated on one $3-capped rented 3090 plus the laptop whenever it is free.

**Architecture:** A v2 prompt builder streams all 50 OpenCodeInstruct files and writes 50k-prompt part files. One generator script talks to any OpenAI-compatible server (vLLM on the box, llama.cpp `llama-server` on the laptop), takes an explicit range of parts, and appends every answer as it arrives, so it can be stopped and resumed at any point. The verifier checks finished parts on the laptop CPU in `quipu.sandbox` and writes kept answers per part.

**Tech Stack:** Python 3 stdlib (urllib, concurrent.futures), pyarrow, huggingface_hub, quipu.decontam, quipu.sandbox, quipu.spend; vLLM (box only, not a project dependency); llama.cpp Windows CUDA build (laptop only); pytest.

**Spec:** `docs/superpowers/specs/2026-10-12-distill-v2-scaled-code-data-design.md`. Two amendments, applied in Task 0:
1. The box and the laptop do not share a disk, so "a part is taken when its file exists" cannot work across machines. Instead each worker gets an explicit part range: box `--parts 0:4 --direction up`, laptop `--parts 5:19 --direction down`. They cannot overlap.
2. v2 prompts get their own ids (`dv2-0000000`); v1 answers (1.5B teacher, old style) are not reused, so there is no id carry-over.
3. The v2 builder is a new script reusing v1's per-row rules (`scripts/build_distill_prompts_v2.py`), so v1 stays byte-for-byte reproducible.

**Standing rules for every task:** never train on or generate training text with Claude; Claude writes no example answers into the teacher prompt; never push to GitHub; commits have no Co-Authored-By or other trailers; do not touch Ollama or processes this work did not start; renting the box needs the user's explicit "yes" on the exact offer and price.

`scripts/build_distill_prompts_v2.py`:

```python
"""Distillation v2 prompt set: all of OpenCodeInstruct, in 50k-prompt part files.

Same per-row rules as v1 (scripts/build_distill_prompts.function_problem: reference
passed every test, 3-15 asserts calling one non-builtin function, problem 150-2500
chars), same decontamination (quipu.decontam, HumanEval and MBPP at the pinned
commits) and whitespace-collapsed exact dedup. APPS is not used (the v1 teacher
passed 31% of it). Files are read one at a time, in a seeded order, and shuffled
within each file, so memory stays at about one parquet file; the dedup set holds
16-byte hashes, not text. Stops at --max-prompts.

Output (default data/distill-v2/prompts/):
- part-NNNN.jsonl: id (dv2-NNNNNNN), part, split (every 20th is "val"), source,
  source_id, licence, kind, prompt, entry_point, tests;
- manifest.json: source files with sha256, rules, counts per drop reason,
  decontamination hits, every part's rows and sha256.

Run:  uv run python scripts/build_distill_prompts_v2.py [--max-prompts 1000000]
"""
from __future__ import annotations

import argparse
import hashlib
import json
import random
import sys
from collections import Counter
from pathlib import Path
from typing import Iterable, Iterator

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))

from quipu.decontam import collapse, load_benchmarks  # noqa: E402
from scripts.build_distill_prompts import (HUMANEVAL_REV, MBPP_REV, OCI,  # noqa: E402
                                           function_problem, sha256)

OCI_FILES = [f"data/train-{i:05d}-of-00050.parquet" for i in range(50)]
VAL_EVERY = 20


class PartWriter:
    """Writes prompts to part-NNNN.jsonl files of part_size rows, numbering ids."""

    def __init__(self, out: Path, part_size: int):
        self.out, self.part_size, self.n = Path(out), part_size, 0
        self.out.mkdir(parents=True, exist_ok=True)
        self.f = None
        self.parts: list[dict] = []

    def _path(self, part: int) -> Path:
        return self.out / f"part-{part:04d}.jsonl"

    def _finish(self) -> None:
        if self.f:
            self.f.close()
            part = len(self.parts)
            p = self._path(part)
            rows = sum(1 for _ in open(p, encoding="utf-8"))
            self.parts.append({"part": part, "file": p.name, "rows": rows, "sha256": sha256(p)})
            self.f = None

    def add(self, p: dict) -> None:
        part = self.n // self.part_size
        if self.f is None or part != len(self.parts):
            self._finish()
            self.f = open(self._path(part), "w", encoding="utf-8", newline="\n")
        rec = {"id": f"dv2-{self.n:07d}", "part": part,
               "split": "val" if self.n % VAL_EVERY == 0 else "train",
               "source": p["source"], "source_id": p["source_id"], "licence": p["licence"],
               "kind": p["kind"], "prompt": p["prompt"],
               "entry_point": p["entry_point"], "tests": p["tests"]}
        self.f.write(json.dumps(rec, ensure_ascii=False) + "\n")
        self.n += 1

    def close(self) -> list[dict]:
        self._finish()
        return self.parts


def take_unique(problems: Iterable[dict], decontam, seen: set[bytes], drops: Counter,
                hits: Counter) -> Iterator[dict]:
    """Yield problems not seen before (by collapsed text) and not contaminated."""
    for p in problems:
        key = hashlib.blake2b(collapse(p["problem"]).lower().encode("utf-8"),
                              digest_size=16).digest()
        if key in seen:
            drops[f"{p['source']}:duplicate"] += 1
            continue
        found = decontam.find(p["prompt"] + "\n" + "\n".join(p["tests"])) if decontam else None
        if found:
            drops[f"{p['source']}:decontam_{found[0]}"] += 1
            hits[found[0]] += 1
            continue
        seen.add(key)
        yield p


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(description=__doc__.split("\n\n")[0])
    ap.add_argument("--max-prompts", type=int, default=1_000_000)
    ap.add_argument("--part-size", type=int, default=50_000)
    ap.add_argument("--files", type=int, default=len(OCI_FILES), help="first N files (tests)")
    ap.add_argument("--seed", type=int, default=1337)
    ap.add_argument("--out", default="data/distill-v2/prompts")
    ap.add_argument("--cache", default="data/distill-src")
    ap.add_argument("--no-decontam", action="store_true", help="tests only")
    args = ap.parse_args(argv)

    import pyarrow.parquet as pq
    from huggingface_hub import hf_hub_download

    rng = random.Random(args.seed)
    files = OCI_FILES[:args.files]
    rng.shuffle(files)
    decontam, bench = (None, {}) if args.no_decontam else load_benchmarks(
        {"humaneval": HUMANEVAL_REV, "mbpp": MBPP_REV})
    writer = PartWriter(ROOT / args.out, args.part_size)
    seen: set[bytes] = set()
    drops: Counter = Counter()
    hits: Counter = Counter()
    shas, rows_read = {}, 0
    for f in files:
        if writer.n >= args.max_prompts:
            break
        p = Path(hf_hub_download(OCI["dataset"], f, repo_type="dataset", revision=OCI["revision"],
                                 local_dir=str(ROOT / args.cache / "oci")))
        shas[f] = sha256(p)
        rows = pq.read_table(p, columns=["id", "input", "unit_tests",
                                         "average_test_score"]).to_pylist()
        rows_read += len(rows)
        cands = []
        for r in rows:
            prob, why = function_problem(r)
            if prob is None:
                drops[f"opencodeinstruct:{why}"] += 1
            else:
                cands.append(prob)
        del rows
        rng.shuffle(cands)
        for prob in take_unique(cands, decontam, seen, drops, hits):
            writer.add(prob)
            if writer.n >= args.max_prompts:
                break
        print(f"{f}: {writer.n} prompts so far", flush=True)
    parts = writer.close()

    manifest = {
        "version": 2, "seed": args.seed,
        "source": {**OCI, "files": sorted(shas), "sha256": shas, "rows_read": rows_read},
        "benchmarks_decontaminated": ({k: {"dataset": v["dataset"], "revision": v["revision"],
                                           "problems": v["problems"]} for k, v in bench.items()}
                                      if bench else "skipped (--no-decontam)"),
        "rules": {"rows": "v1 function_problem: average_test_score == 1.0; 3-15 asserts "
                          "calling one non-builtin function; problem 150-2500 chars",
                  "dedup": "whitespace-collapsed lowercase text, blake2b-128",
                  "decontam": "prompt + tests through quipu.decontam",
                  "val": f"every {VAL_EVERY}th prompt", "max_prompts": args.max_prompts,
                  "part_size": args.part_size},
        "total": writer.n, "parts": parts,
        "drops": dict(sorted(drops.items())), "decontam_hits": dict(hits),
    }
    (ROOT / args.out / "manifest.json").write_text(json.dumps(manifest, indent=1) + "\n",
                                                  encoding="utf-8")
    print(json.dumps({"total": writer.n, "parts": len(parts), "decontam_hits": dict(hits)}))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

`scripts/distill_generate_v2.py` (the CLI is added in Task 4):

```python
"""Distillation v2, step 1: the teacher answers a range of prompt parts.

Talks to any OpenAI-compatible /v1/chat/completions server: vLLM on the rented box
(bf16), llama.cpp llama-server on the laptop (4-bit GGUF). Teacher:
Qwen/Qwen2.5-Coder-7B-Instruct (Apache-2.0). Greedy decoding, the fixed
SYSTEM_PROMPT below (a description of the answer style only; no example answers),
the problem as the user turn.

Each worker gets an explicit part range (--parts START:END, --direction up|down;
box 0:4 up, laptop 5:19 down), skips parts that have a .done sidecar and works the
first unfinished one. Every answer is appended and flushed as it arrives, so
stopping at any point loses only in-flight requests; rerunning resumes. Creating
data/distill-v2/PAUSE makes it finish in-flight requests and exit. On the box,
--budget-usd stops it when quipu.spend reports the cap reached.

Output: generations/part-NNNN.<tag>.jsonl rows: id, part, teacher, revision,
teacher_tag, response, finish ("eos" | "length"), new_tokens; and, when every
prompt of the part is answered, part-NNNN.<tag>.done: {"rows", "sha256"}.
"""
from __future__ import annotations

import hashlib
import json
import sys
import threading
import time
from concurrent.futures import FIRST_COMPLETED, ThreadPoolExecutor, wait
from pathlib import Path
from typing import Callable

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))

TEACHER = "Qwen/Qwen2.5-Coder-7B-Instruct"

SYSTEM_PROMPT = (
    "Start with one or two sentences restating what the problem asks and the approach "
    "you'll take. Then give a short numbered plan (2-4 steps). Then the complete function "
    "in one ```python block, with clear names and a brief docstring, and comments only "
    "where the logic isn't obvious. End with a short \"Edge cases\" line covering empty "
    "input, boundaries, and time complexity. Be direct and friendly, don't repeat "
    "yourself, and no filler like \"Great question!\"."
)

Chat = Callable[[str, str, int], "tuple[str, str, int]"]  # -> (text, finish_reason, tokens)


def part_order(spec: str, direction: str) -> list[int]:
    start, end = (int(x) for x in spec.split(":"))
    parts = list(range(start, end + 1))
    return parts[::-1] if direction == "down" else parts


def gen_paths(root: Path, part: int, tag: str) -> tuple[Path, Path]:
    g = Path(root) / "generations"
    return g / f"part-{part:04d}.{tag}.jsonl", g / f"part-{part:04d}.{tag}.done"


def is_done(root: Path, part: int) -> bool:
    return any((Path(root) / "generations").glob(f"part-{part:04d}.*.done"))


def done_ids(path: Path) -> set[str]:
    out: set[str] = set()
    if path.exists():
        for line in open(path, encoding="utf-8"):
            try:
                out.add(json.loads(line)["id"])
            except (ValueError, KeyError):
                continue  # a torn last line from an interrupted run
    return out


def _sha256(path: Path) -> str:
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def _ensure_newline(path: Path) -> None:
    """A torn last line must not swallow the next appended row."""
    if path.exists() and path.stat().st_size:
        with open(path, "rb") as f:
            f.seek(-1, 2)
            if f.read(1) != b"\n":
                with open(path, "ab") as g:
                    g.write(b"\n")


def run_part(root: Path, part: int, tag: str, chat: Chat, *, concurrency: int,
             max_new_tokens: int, teacher: str, revision: str,
             over_budget: Callable[[], bool] = lambda: False) -> str:
    """Answer every unanswered prompt of one part.
    Returns "done" | "paused" | "budget" | "incomplete" (some requests failed)."""
    root = Path(root)
    prompts = [json.loads(l) for l in open(root / "prompts" / f"part-{part:04d}.jsonl",
                                           encoding="utf-8") if l.strip()]
    out, done_file = gen_paths(root, part, tag)
    out.parent.mkdir(parents=True, exist_ok=True)
    _ensure_newline(out)
    have = done_ids(out)
    todo = [p for p in prompts if p["id"] not in have]
    pause = root / "PAUSE"
    lock = threading.Lock()
    failed = 0
    stop = ""
    t0, n_tok, n_new = time.time(), 0, 0

    def one(p: dict) -> None:
        nonlocal n_tok, n_new
        text, reason, tokens = chat(SYSTEM_PROMPT, p["prompt"], max_new_tokens)
        rec = {"id": p["id"], "part": part, "teacher": teacher, "revision": revision,
               "teacher_tag": tag, "response": text,
               "finish": "length" if reason == "length" else "eos", "new_tokens": tokens}
        with lock:
            f.write(json.dumps(rec, ensure_ascii=False) + "\n")
            f.flush()
            n_tok += tokens
            n_new += 1
            if n_new % 200 == 0:
                el = time.time() - t0
                print(f"part {part}: {len(have) + n_new}/{len(prompts)}, "
                      f"{n_tok / el:.0f} tok/s", flush=True)

    with open(out, "a", encoding="utf-8", newline="\n") as f, \
            ThreadPoolExecutor(concurrency) as ex:
        it = iter(todo)
        running: set = set()
        last_budget_check = 0.0
        while True:
            if not stop and pause.exists():
                stop = "paused"
            if not stop and time.time() - last_budget_check > 60:
                last_budget_check = time.time()
                if over_budget():
                    stop = "budget"
            while not stop and len(running) < concurrency:
                p = next(it, None)
                if p is None:
                    break
                running.add(ex.submit(one, p))
            if not running:
                break
            finished, running = wait(running, return_when=FIRST_COMPLETED)
            for fut in finished:
                if fut.exception() is not None:
                    failed += 1
                    print(f"request failed: {fut.exception()!r}", flush=True)

    if stop:
        return stop
    if failed or len(done_ids(out)) < len(prompts):
        return "incomplete"
    done_file.write_text(json.dumps({"rows": len(prompts), "sha256": _sha256(out)}) + "\n",
                         encoding="utf-8")
    return "done"
```

Note on the budget test: `last_budget_check` starts at 0, so the first loop iteration checks the budget before submitting anything.

def make_chat(endpoint: str, model: str = "teacher", timeout: float = 600.0,
              retries: int = 3) -> Chat:
    """A chat() for an OpenAI-compatible server (vLLM, llama-server)."""
    import urllib.error
    import urllib.request

    url = endpoint.rstrip("/") + "/v1/chat/completions"

    def chat(system: str, user: str, max_tokens: int) -> tuple[str, str, int]:
        body = json.dumps({"model": model, "temperature": 0, "max_tokens": max_tokens,
                           "messages": [{"role": "system", "content": system},
                                        {"role": "user", "content": user}]}).encode()
        for attempt in range(retries):
            try:
                req = urllib.request.Request(url, data=body,
                                             headers={"Content-Type": "application/json"})
                with urllib.request.urlopen(req, timeout=timeout) as r:
                    d = json.loads(r.read())
                c = d["choices"][0]
                return (c["message"]["content"] or "", c.get("finish_reason") or "stop",
                        int(d.get("usage", {}).get("completion_tokens", 0)))
            except (urllib.error.URLError, TimeoutError, ConnectionError):
                if attempt == retries - 1:
                    raise
                time.sleep(5 * (attempt + 1))
        raise RuntimeError("unreachable")

    return chat


def spend_over(budget: float) -> Callable[[], bool]:
    """True when quipu.spend says the cap is reached; fails closed."""
    import subprocess

        r = subprocess.run([sys.executable, "-m", "quipu.spend", "show", "--usd-only"],
                           cwd=ROOT, capture_output=True, text=True)
        if r.returncode != 0:
            print("spend ledger unreadable: stopping", flush=True)
            return True
        return float(r.stdout.strip()) >= budget

    return check

def verify_part(root: Path, part: int, workers: int, timeout: float) -> dict | None:
    """Verify one part's finished generations; None when already up to date."""
    root = Path(root)
    gdir = root / "generations"
    done = sorted(gdir.glob(f"part-{part:04d}.*.done"))
    if not done:
        return None
    srcs = sorted(gdir.glob(f"part-{part:04d}.*.jsonl"),
                  key=lambda p: _tag_rank(p.name.split(".")[1]))
    stamp = {p.name: [p.stat().st_size, p.stat().st_mtime_ns] for p in srcs}
    meta_path = root / "verified" / f"part-{part:04d}.meta.json"
    if meta_path.exists() and json.loads(meta_path.read_text(encoding="utf-8")) == stamp:
        return None
    problems = {json.loads(l)["id"]: json.loads(l)
                for l in open(root / "prompts" / f"part-{part:04d}.jsonl", encoding="utf-8")
                if l.strip()}

                continue

                chosen[g["id"]] = g

    with ThreadPoolExecutor(workers) as ex:
        results = list(ex.map(lambda g: check(problems[g["id"]], g, timeout), gens))

# Distillation v2 on a rented box: vLLM (bf16 teacher) + generator for parts 0..4,
# stopping at the spend cap. Run in tmux from /workspace/quipu after setup.sh:

- [ ] **Step 2: Pull script** (laptop side; copies finished parts and partial files, sha-checks finished ones)

`scripts/remote/pull_distill_v2.sh`:

```bash
#!/usr/bin/env bash
# Copy distill v2 generations back from the box: bash scripts/remote/pull_distill_v2.sh HOST PORT
set -euo pipefail
HOST=$1; PORT=$2
DEST=data/distill-v2/generations
mkdir -p "$DEST"
scp -P "$PORT" -o StrictHostKeyChecking=no "root@$HOST:/workspace/quipu/data/distill-v2/generations/part-*.bf16-vllm.*" "$DEST/"
for d in "$DEST"/part-*.bf16-vllm.done; do
  [ -e "$d" ] || continue
  f=${d%.done}.jsonl
  want=$(python -c "import json,sys; print(json.load(open(sys.argv[1]))['sha256'])" "$d")
  got=$(sha256sum "$f" | cut -d' ' -f1)
  [ "$want" = "$got" ] && echo "OK $(basename "$f")" || { echo "HASH MISMATCH $(basename "$f")"; exit 1; }
done
```

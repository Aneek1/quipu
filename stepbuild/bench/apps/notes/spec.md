A notes app where each note has an integer `id` assigned by the server, a required `title` (a non-empty string) and a `body` (a string that defaults to an empty string when it is left out). The API has five JSON endpoints: `GET /api/notes` returns all notes as a JSON array; `POST /api/notes` creates a note from a JSON body with `title` and optional `body` and returns the new note with its `id` and status 201; `GET /api/notes/<id>` returns one note; `PUT /api/notes/<id>` updates the `title` and/or `body` of a note and returns the updated note; `DELETE /api/notes/<id>` deletes a note and returns 200 or 204. A missing or empty `title`, or a `body` that is not a string, is rejected with status 400 and a JSON body with an `error` key, and any request for an `id` that does not exist returns 404. The page shows the list of notes (title and body) with a delete button on each and a form to add a new note.

A todo list where each todo has an integer `id` assigned by the server, a required `title` (a non-empty string) and a `done` flag (a boolean that defaults to false when it is left out). The API has five JSON endpoints: `GET /api/todos` returns all todos as a JSON array; `POST /api/todos` creates a todo from a JSON body with `title` and optional `done` and returns the new todo with its `id` and status 201; `GET /api/todos/<id>` returns one todo; `PUT /api/todos/<id>` updates the `title` and/or `done` of a todo and returns the updated todo; `DELETE /api/todos/<id>` deletes a todo and returns 200 or 204. A missing or empty `title`, or a `done` that is not a boolean, is rejected with status 400 and a JSON body with an `error` key, and any request for an `id` that does not exist returns 404. The page shows the list of todos with a delete button on each and a form to add a new todo.

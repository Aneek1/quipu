An inventory app where each stock item has an integer `id` assigned by the server (ids are never reused, even after a delete), a required `name` (a string that is not empty after trimming whitespace) and a `quantity` (a whole number of 0 or more: a JSON integer, not a boolean and not a decimal, which defaults to 0 when it is left out); every new app instance starts with no items. The API has five JSON endpoints for items and one for taking stock out: `GET /api/items` returns all items as a JSON array; `POST /api/items` creates an item from a JSON body with `name` and optional `quantity` and returns the new item with its `id` and status 201; `GET /api/items/<id>` returns one item; `PUT /api/items/<id>` updates an item and returns the updated item with status 200, where PUT accepts any subset of the fields; fields left out keep their values; a field that is sent follows the same rules as on create (so an empty `name` is 400); `DELETE /api/items/<id>` deletes an item and returns 200 or 204. `POST /api/items/<id>/decrement` takes stock out, from a JSON body with a required `amount` (a whole number of 1 or more: a JSON integer, not a boolean and not a decimal); it returns the updated item with its lowered `quantity` and status 200, but when the amount is more than the current quantity (so stock would go below zero) it returns status 409 with a JSON body with an `error` key and leaves the quantity unchanged. Taking out exactly the current quantity is allowed and leaves 0. The validation rules, each rejected with status 400 and a JSON body with an `error` key, are: `name` missing, not a string, or empty after trimming whitespace; `quantity` sent but not an integer (booleans and decimals are rejected) or negative; a decrement `amount` missing, not an integer (booleans and decimals are rejected), or less than 1. A field sent as `null` counts as sent, so `null` for a field is 400. Any request for an `id` that does not exist returns 404, including the decrement endpoint. The page shows the list of items (name and quantity) with a delete button on each and a form to add a new item.
